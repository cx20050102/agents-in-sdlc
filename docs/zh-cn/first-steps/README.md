入门体验研讨会通过引导式介绍，帮助你了解 GitHub Copilot，无需已有应用或详细的开发场景。每个研讨会都从简单任务开始，在实际操作中介绍产品，并带你完成完整的工作流。

每个研讨会都会从空文件夹构建同一个 Space Quiz。你可以选择想了解的工具，也可以完成多个研讨会，对比不同工具的工作方式。

> [!NOTE]
> 这些研讨会由 [James Montemagno][james] 创建，改编自 [First Steps with GitHub Copilot][source-lab]，原内容采用 [MIT 许可证][source-license]。

## 研讨会

### [GitHub Copilot app 导览][copilot-app]

从空文件夹构建色彩丰富的 Space Quiz，并完成整个开发流程：创建、优化、测试、记录项目指令、发布、规划工作、实现议题、审查并合并拉取请求、自动化重复工作，以及探索 Canvas 扩展。

### [GitHub Copilot CLI 入门][copilot-cli]

体验以终端为中心的工作流：在 Git 执行写入操作前构建并审查差异，在工作树中并行运行会话，先规划再编辑，管理上下文，然后不离开 shell 即可创建、合并和委派工作。

### [Visual Studio Code 入门][vscode]

体验以编辑器为中心的工作流：在工作区中构建，从集成浏览器中优化页面，检查上下文，在 Git 执行写入操作前进行测试，先规划再编辑，并在 VS Code 中使用 GitHub 工具处理议题、拉取请求和云会话。
